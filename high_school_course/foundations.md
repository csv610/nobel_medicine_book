# Foundations: Tools for the Course

## 1. A useful investigation cycle

1. Ask a question that can be answered with evidence.
2. State a testable prediction.
3. Choose variables and a comparison or control.
4. Collect measurements consistently.
5. Represent the data in a table or graph.
6. Explain uncertainty and alternative explanations.
7. Revise the question or design a follow-up test.

## 2. Core ideas

- **Cell:** the basic organized unit of life.
- **Homeostasis:** keeping internal conditions within a workable range.
- **Gene:** a DNA sequence that contributes to a biological product or process.
- **Protein:** a molecule whose shape and chemical properties enable cellular work.
- **Pathogen:** an organism or agent that can cause disease.
- **Immune response:** coordinated defenses that recognize and respond to threats.
- **Correlation:** two measurements vary together; it does not automatically show causation.
- **Control:** a comparison that helps identify what caused an observed difference.

## 3. Data habits

Label axes with units, show all observations, keep raw data, and report the sample size. Averages can hide variation, so show a range or individual points when possible. Never remove an inconvenient result without documenting why.

## 4. Basic calculations

`rate = change / time`

`percent change = (new - original) / original × 100`

For a fair comparison, change one main factor at a time and keep other conditions as similar as practical.
